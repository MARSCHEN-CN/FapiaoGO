# FapiaoGO v1.0.0 Release Notes

> 首个正式版本（First Stable Release）
> Git Tag：`v1.0.0` ｜ 构建产物：Windows x64 ｜ 框架：Electron 43.4.1 + 本地 Python 引擎

---

## 🎉 版本概览

FapiaoGO 是面向日常发票管理场景的桌面工具：导入、识别、预览、打印、导出一条龙。v1.0.0 为第一个正式发布版本，完成打印链路、数据持久化、打包工程与稳定性四轮 Gate 验收，可作为生产环境基准。

---

## ✨ 核心功能

### 1. 发票导入与智能识别
- 支持 **PDF / OFD / 常见图片**（jpg、png 等）格式发票导入
- 内置 **OCR 识别引擎**（onnxruntime），自动提取发票号码、金额、日期等关键字段
- 批量导入（多线程调度），导入进度可视化

### 2. 高保真预览
- 内置文档查看器，PDF / OFD 逐页渲染，支持翻页、旋转
- 预览渲染与打印渲染分层隔离，所见即所得

### 3. 打印（核心能力）
- 基于 Sumatra 打印引擎，精准输出（noscale 免缩放失真）
- **纸张方向自适应**：横向/纵向凭证纸自动适配，旋转语义统一
- **多票合并打印**：多张发票合并排版后一次打印
- **安全边距控制**：统一固定纸坐标系 contain-fit 边距，避免裁切与监制章丢失
- 打印设置持久化（纸张方向、内容旋转等）

### 4. 数据导出
- 发票明细 **Excel 导出**，字段可选，金额合计与前端所见精确一致（Decimal 精度）
- 多页 PDF 组合 / 打包导出

### 5. 辅助工具
- 内置**计算器**（随分辨率自适应尺寸）
- 批量重命名、文档分组管理

---

## 🛡 稳定性与工程质量（v1.0.0 关键修复）

- **修复冷启动崩溃**：修复模块加载期 `path.join(undefined)` 导致的启动即崩问题，双击启动回归通过
- **生产环境加固**：禁用 DevTools 与默认菜单，子进程统一 `windowsHide`，不再泄漏控制台黑窗
- **数据安全**：数据目录与安装目录分离，**卸载程序不会删除发票数据**；旧版本数据自动迁移
- **打印链路四层隔离**：身份 / 执行计划 / 预览资源 / 渲染资源解耦，32 组真机打印案例物理实测通过
- **默认浅色主题**，尊重用户显式深色选择

## ⚠️ 注意事项

- **数据位置**：发票与配置数据保存在独立用户数据目录（非安装目录），重装/卸载不影响数据
- **首次升级**：如使用过早期预览版，首次启动会自动迁移旧数据
- **杀毒软件**：便携版/安装版首次运行如被拦截，请将安装目录加入白名单（本地 Python 引擎属正常行为）
