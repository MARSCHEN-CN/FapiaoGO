# FapiaoGO v1.0.1 Release Notes

> 维护更新（Patch Release）｜ 上一个版本：[v1.0.0](../../releases/tag/v1.0.0)
> Git Tag：`v1.0.1` ｜ 构建产物：Windows x64 ｜ 框架：Electron 43.4.1 + 本地 Python 引擎

---

## 📌 版本概览

v1.0.1 是 v1.0.0 之后的维护性更新，**不涉及新功能**，重点解决三类真实使用问题：

1. **点击发票后预览不显示**——v1.0.0 中最影响日常使用的问题，本次从三个独立成因上修复
2. **发票识别准确率**——购销方名称、免税票税额、明细行列切分的具体错判
3. **大批量导入**——导入历史查询由「数百次零散请求」改为批量原子发布

本次更新的生产代码改动全部经过红测试 → 实现 → 绿测试 → 真机回归链路。

---

## 🐛 问题修复

### 1. 自动预览 / 点击预览（重点）

v1.0.0 中存在「导入后不自动出预览」「点击列表里另一张发票后预览不切换、需要再点一次」「预览区长时间空白」等现象。根因不是一个 bug，而是三个独立缺陷叠加，本次一并修复：

| # | 成因 | 表现 | 修复 |
|---|---|---|---|
| X1 | 预览提交后执行态没有终态化，后续刷新请求被判为「需重启」而全部扑空 | 预览卡住不动，反复刷新无效 | 三个提交出口（成功/缓存/保险丝拦截）统一置空执行态，兑现「提交即终止」契约 |
| X2 | 防抖只按到达顺序「后来者赢」，不看意图 | 用户的**点击选择**被同 key 的**自动刷新**顶掉，要点第二次才生效 | 新增意图仲裁：同一时间窗口内，用户主动选择优先于自动刷新 |
| X3 | 「半壳快照」（内容已到、文档 ID 未就绪）被当作有效预览提交 | 展示区空白且被固化，所有重试守卫被屏蔽 | 新增可展示性判定闸门，不可展示的快照不得成为已提交预览 |

> 相关运行时取证：8 份发票样本的完整调用时间轴分析，修复前一次成功的自动预览需要用户手动补点才触发。

### 2. 发票识别准确率

**购销方名称解析**
- 补齐「馆」「家」「社」等公司后缀——修复「XX烧鸡馆」「XX咖啡馆」「XX美食家」等名称解析失败
- 名称含分支机构时不再被截断——现在可正确保留「天津分公司」「第二分公司」「XX分行」「XX分店」
- 名称匹配正则主体改为非贪婪，避免过度吞并

**金额与税额**
- 修复免税发票税额被误读的问题（实测案例：税额 `21.73` → 正确值 `0.00`）

**明细行切分**
- 修复六列边界偏移导致**项目名称末尾字被切进单价列**
- 合计行检测兼容空格分隔写法
- 新增「出行人」表头终止词，适配火车票 / 机票类凭证
- 双通路（PDF 文本层 + OCR）列名兼容与抗污染处理

**导出**
- 补全 Excel 导出的字段键映射

### 3. 大批量导入

- **导入历史查询改为批量 + 原子发布**：原先每批导入回包都会触发全量重排与数百次零散 HTTP 查询，现在响应先合入待发布区，50ms 防抖合并为单次提交，内容无变化则不发布
- 后端新增导入历史批量查询接口
- 修复「仅排序变更」场景下查询守卫被意外清除的问题

### 4. 数据安全

- 数据迁移器增加 `.migration_done` 完成标记，防止删除 `database/` 目录时旧数据被回拷覆盖
- 迁移标记**仅在完整成功时落盘**——部分失败不落标记，保留失败项的重试能力

### 5. 界面细节

- 侧栏搜索框固定——修正 flex 高度约束链断裂导致的列表双滚动问题
- 发票详情面板改为等宽字体，金额与编号对齐更易读

## 🔧 工程与可观测性

本次随包附带两个**默认关闭**的观测模块（`previewTrace`、`importPerfProbe`），用于日后定位预览与导入问题。它们由手动开关启用，**默认状态下不影响任何行为与性能**。

同时，v1.0.0 之后一度引入的预览性能诊断开关与分层测量探针，**已在本次发布前全部回退**——已实证确认当前发布包的生产代码与诊断前基准完全一致（差异仅为 1 行版本号），发布包不包含任何实验性代码。

## ⚠️ 已知问题

| 项目 | 说明 |
|---|---|
| **代码签名** | 安装包与主程序**尚未进行代码签名**。首次运行时 Windows SmartScreen 会显示「Windows 已保护你的电脑」提示，点击**「更多信息」→「仍要运行」**即可继续，不影响功能 |
| 预览切换耗时 | 切换发票时偶发的固定约 313ms 延迟，其归因判定（Constant-Latency Attribution Gate）尚未启动，**本次不包含相关优化** |
| 体积 | 解包后约 650MB，与 v1.0.0 持平（内置完整 OCR 引擎与 Python 运行时） |

## ⬆️ 升级说明

- **从 v1.0.0 升级**：直接运行安装包覆盖安装即可，**发票数据不会被删除**（数据目录与安装目录分离）

- 绿色版：解压后覆盖同名目录即可，同样不影响 `database/` 与 `userdata/` 下的数据
- 本次版本号更新覆盖全部显示位置：侧栏版本徽标、关于对话框、检查更新弹窗
